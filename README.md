#### Hello world written in C using GCC inline assembly. 

`everyline.c` spreads one token per line, by far the most efficient way to waste file size in newline characters.

`oneline.c` is the polar opposite, containing the whole program in a single line like it was always meant to be. 

`normal.c` is the lame, properly indented, boring version. To be fair, i did write it before the other ones. 

#### Requirements:
- x86_64 (amd64) CPU
- 64 bit linux kernel >= 2.6 (may work on earlier but not guaranteed)
- `gcc` version >= 4.x (guaranteed)
  - `gcc` itself depends on: the GNU `as` assembler and the `ld` linker
- `clang` version >= 3.x (guaranteed)
  - `clang` itself depends on: the `ld` linker

- Optional:
  - `make`: you can compile it yourself without make, but use the flags shown inside `Makefile`. 
  - `git`: useful to clone this repository, but you can just copy-paste the files (with their proper names) and proceed normally.

#### Compile and run:
Given the requirements have been met, you can:
```shell
git clone --depth=1 https://github.com/AGMOs713/everyline.git
```
or (through SSH):
```shell
git clone --depth=1 git@github.com:AGMOs713/everyline.git
```
Then:
```shell
cd everyline
make
```
Available arguments for `make`:
```shell
make # compile but not run
make all # same as previous
make run # compile and run
make clean # delete files generated by compiling with make
```
